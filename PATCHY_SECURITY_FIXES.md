### web2/exec/app.py
**Issue:** Replaced use of Python's raw exec on untrusted input with RestrictedPython. We compile the user code under a restricted execution environment (no dangerous builtins) and only expose a minimal safe builtins map. We also capture any user-defined 'result' variable instead of returning arbitrary stdout.

**Security Notes:** - RestrictedPython significantly reduces risk but does not guarantee full isolation. For higher assurance, consider running in a container or separate process with OS-level restrictions and resource/time limits.
- Monitor execution duration and memory usage to prevent DoS.
