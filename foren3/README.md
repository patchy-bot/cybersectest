# 2^3

## Description

The number eight might be the perfect number. Check out this cool octagonal fractal!

## Flag

`wxmctf{0n3_tW0_THR33_F0ur_fiV3_5IX_53v3N_3i9Ht!}`

## Solution

The flag is split into eight parts: `wxmctf{0n3 _tW0 _THR33 _F0ur _fiV3 _5IX _53v3N _3i9Ht!}`. Each part is hidden the respective bit of the image. For example, `wxmctf{0n3` is hidden in the most significant bit, while `_3i9Ht!}` is hidden in the least significant bit.
