## 🔧 Security Fixes Provided


### 1. web2/exec/app.py
**Vulnerability:** CODE_INJECTION  
**Confidence:** HIGH  
**Breaking Changes:** No

**Explanation:** Replaced unrestricted Python exec() with a safe evaluator that uses AST to allow only numeric literals and arithmetic operators. The safe_eval function parses the input expression, checks every node against a whitelist, and then evaluates it in a sandboxed environment with no builtins.

**Security Notes:** • Always run untrusted code in the smallest possible sandbox.  
• Consider third-party sandboxing libraries (e.g. RestrictedPython) for more complex use cases.  
• Log and alert on rejected expressions for monitoring.

**Additional Dependencies:**
- import ast

**Testing Recommendations:**
- Submit valid arithmetic expressions and verify correct results
- Submit malicious payloads (e.g. __import__('os').system('ls')) and verify they are rejected
